websandbox

Lightweight, self-hostable websites for training and evaluating web agents: a store with its back office, a forum, a code-hosting site, a Wikipedia and a map, rebuilt from the WebArena environments with the same kinds of features and the same underlying data, plus new sites (webmail, a community site) whose content is generated from a simulated world of people. Each site is one SQLite database plus one small Node server that resets in milliseconds. This is a public demo instance (one copy of each site).

Everything you change here is shared with other visitors and is undone every {{RESET_MIN}} minutes: all sites reset to their initial state (last reset {{LAST_RESET}}, next {{NEXT_RESET}}). Please don't enter real personal data.
